# Telegram Bot Da-Pizda

Telegram-бот с модульной архитектурой.

## Функционал
* Ежедневная игра «Пидор дня» по расписанию
* Mini-game «Гномья дуэль на ножах» (`/duel`) с динамическими шансами победы и кражей хуев
* Поддержка текстовых триггеров и реакций на сообщения
* Учёт дней рождения пользователей
* Команда `/top` для вывода статистики по красавчикам
* Команда `/force_pidor` для принудительного выбора пидора дня
* Команда `/weather` для вывода погоды в желаемом городе
* Отложенные ответы «Пизда» на старые сообщения «да» (джоба раз в 2–7 дней, 10:00–22:00 МСК)

## Гномья дуэль на ножах (`/duel`)

Игроки могут вызывать друг друга на дуэль командным вызовом `/duel @username`.

* **Механика очков:** У каждого игрока ежедневно есть стартовый баланс в 20 очков (максимум — 100). Победитель получает **+10 очков**, проигравший теряет **-5 очков**. При 0 очков драться в этот день больше нельзя.
* **Шансы на победу:** Рассчитываются динамически пропорционально текущим очкам участников:
  $$\text{Шанс победы} = \frac{\text{Очки игрока}}{\text{Очки игрока} + \text{Очки противника}}$$
  *(При равных очках шанс составляет 50/50)*.
* **Кража хуя:** С настраиваемой вероятностью у проигравшего дуэлянта может быть **украден хуй** — после этого он больше не может участвовать в дуэлях до наступления следующих суток.
* **Сброс результатов:** Каждый день в 00:00 (по заданному часовому поясу `Europe/Moscow`) очки автоматически сбрасываются до 20, а статусы «украденного хуя» аннулируются.

**Команды дуэлей:**
* `/duel @username` — вызвать игрока на дуэль.
* `/duel_stats` или `/stats` (`/stats @username`) — посмотреть личную статистику дуэлей или статистику другого игрока.
* `/duel_top` — посмотреть топ лучших дуэлянтов.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Emanloe/da-pizda-bot.git
   cd da-pizda-bot
   ```

2. Скопируйте файл конфигурации и укажите ваш токен и телеграм айди:
   ```bash
   cp .env.example .env
   ```

3. Запустите через Docker:
   ```bash
   docker build -t da-pizda-bot .
   docker run -d \
     --name da-pizda-bot \
     --restart always \
     --env-file .env \
     -v $(pwd)/bot_database.db:/app/bot_database.db \
     da-pizda-bot
   ```
